# C++ Task CLI App

A simple command-line task manager built in C++ that supports adding, viewing, completing, saving, and loading tasks using file I/O.

---

## Features

- Add new tasks
- View all tasks
- Mark tasks as completed
- Save tasks to a file (`tasks.txt`)
- Load tasks automatically on startup

---

## Concepts Used

- Structs
- Vectors
- Functions
- File I/O (`ifstream`, `ofstream`)
- Pass-by-reference
- Multi-file project structure

---

## How to Build

Compile using g++:
g++ main.cpp task.cpp -o app

---
## How to Run

Windows (PowerShell):
app.exe

Mac/Linux:
./app

---
## Project Structure

main.cpp -> Program flow (menu system)
task.cpp -> Function implementations
task.h -> Declarations / interface
